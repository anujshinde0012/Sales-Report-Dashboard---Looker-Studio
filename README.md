# Sales Report Dashboard — Looker Studio

## Overview
This project is an interactive **Sales Report Dashboard** created using
**Google Looker Studio (formerly Google Data Studio)**.
The dashboard provides a visual overview of sales-related data through
interactive charts, KPIs, and data visualizations.
